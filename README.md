# Система управления студентами (СУБД)

## Описание проекта

Проект представляет собой систему управления данными о студентах с поддержкой двух типов хранения: in-memory (в оперативной памяти) и файловая база данных (JSON). Реализован с использованием объектно-ориентированного подхода и покрыт автоматизированными тестами.

## Функциональность

- CRUD операции: создание, чтение, обновление, удаление записей о студентах
- Валидация данных: проверка возраста (0-120), среднего балла (0-5), email (формат и уникальность), имени/фамилии (мин. 2 символа)
- Поиск с фильтрацией по любому полю
- Сортировка по любому полю (возрастание/убывание)
- Два типа хранения данных:
  - In-memory: данные хранятся только в оперативной памяти (теряются после завершения программы)
  - File (JSON): данные сохраняются в файлы и восстанавливаются при следующем запуске
- Консольный интерфейс с выбором типа базы данных при запуске
