## Описание проекта

Данный проект представляет собой **объектно-ориентированную in-memory базу данных** для управления студентами, переработанную из предыдущей лабораторной работы. Проект демонстрирует применение принципов ООП, разработку через тестирование (TDD) и автоматизированное тестирование.

   - `delete_record` - удаление записи
