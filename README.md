## Реализованная функциональность

1. **Сохранение ООП архитектуры** - все классы сохранены и расширены
2. **Класс файловой БД** - JSONDatabase и CSVDatabase через единый интерфейс
3. **Персистентность** - данные сохраняются на диск и загружаются при запуске
4. **Полная поддержка CRUD операций** - create, read, update, delete
5. **JSON хранение** - структура таблицы и записи в формате JSON
6. **Обработка ошибок** - все исключения обрабатываются
7. **Тесты** - покрытие >80%
8. **Обновлённый README**

- Отдельный класс CSVDatabase
- Сохранение данных в CSV файлах
- Мета-информация в отдельном JSON файле
- Класс Index для ускорения поиска
- Индексация по любым полям
- Автоматическое обновление индексов при CRUD операциях
- Управление индексами через интерфейс
